# Pizza Delivery Full-Stack Application

A production-grade full-stack pizza ordering and inventory management platform built as part of the Oasis Infobyte internship.

## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Planned Integrations
- JWT Authentication
- Razorpay Test Mode
- Socket.IO
- Nodemailer
- node-cron

## Features

### User
- Registration and email verification
- JWT authentication
- Password reset
- Pizza dashboard
- Custom pizza builder
- Order summary
- Razorpay test payments
- Real-time order tracking

### Admin
- Separate admin authentication
- Inventory management
- Automatic stock deduction
- Manual stock updates
- Low-stock email notifications
- Order management
- Real-time order status updates
